# LLM From Scratch — Interactive React + Vite Roadmap

A zero-to-GPT interactive learning roadmap built with React, Vite, and Tailwind CSS for beginners learning to build Large Language Models from scratch in Python & PyTorch.

## Run Locally
```bash
npm install
npm run dev
```

## Deploy to Netlify or Vercel
1. Push this folder to a GitHub repository (or drag-and-drop `dist/` after running `npm run build`).
2. On **Netlify** or **Vercel**, import the repo—`netlify.toml` and `vercel.json` are already configured!
   - **Build command:** `npm run build`
   - **Output directory:** `dist`
